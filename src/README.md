# 📦 Source Code

This folder contains all source code for the MCP (Model Context Protocol) demo examples.

## Structure

| Subfolder | Description |
|-----------|-------------|
| `mcp-server/` | MCP server implementations and examples |
| `mcp-client/` | MCP client implementations and examples |
| `samples/` | End-to-end sample applications |

## Getting Started

Each example includes its own `README.md` with setup and run instructions. Browse the subfolders above to explore the available demos.

> **Tip:** Start with the [docs](../docs/README.md) folder for architecture overviews and guides before diving into code.
